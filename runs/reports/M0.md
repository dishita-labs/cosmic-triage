## Decisions made (non-obvious, unilateral)

1. **Toolchain:** installed `uv` via Homebrew; `uv` provisioned CPython 3.12.15 (system Python is 3.14).
2. **Contracts are strict:** `extra="forbid"`, `frozen=True`, `allow_inf_nan=False`. `extra="forbid"` makes the Snapshot field list the type-level denylist boundary; NaN (common in Fink JSON) is converted to `None` before construction. Tuples instead of lists for immutability.
3. **Additive contract types** beyond §13.3's list (allowed as additive): `FinkAlertRow`, `StampPrior`, `ValidationCheck`, `ScheduledObservation`, `ActionValue`, `RunManifest`, `MoonState`, `FrameCandidate`, `FacilityState`, `TheaterEvent`, `TheaterNight`. `TheaterNight` gained two optional presentation fields (`min_altitude_deg`, `site_timezone`).
4. **Cache = fixture format.** Every external call goes through `ingest.Cache` keyed by `(client, method, canonical params)`; recorded fixtures are cache entries under `tests/fixtures/cache/`, read with `Cache(offline=True)`. `pytest-recording` is installed but not needed. Tests additionally monkeypatch sockets to raise, so a hidden network call fails loudly.
5. **Schema snapshot test** (`tests/contracts/schema_snapshot.json`); refresh deliberately with `scripts/update_schema_snapshot.py`.
6. **`btsbot` isolation:** it pulls torch/timm/wandb, so KT #8 runs it in a throwaway venv in the session scratchpad (`scripts/kt8_btsbot.py --venv …`), never in the project env. Used the image-only ConvNeXt (galaxyzoo) model; the multimodal model needs 25 alert-packet features (M7). FITS stamps (not PNG) are required for BTSbot normalisation — `AlerceClient.stamp(fmt="fits")` added.
7. **SIMBAD/NED via TAP** through the shared cache instead of `astroquery` (keeps every call cached and fixture-recordable). NED's column is `prefphytype`, frame `J2000`.
8. **Corpora parsing strips post-dated content:** ATel pages embed "Referred to by" and "Related" lists of *later* telegrams; AstroNote listings embed the object's *current* TNS type/redshift in tooltips. Both are dropped at parse time and covered by tests. AstroNote dates are "last modified" and must be treated as an upper bound by the M2 as-of filter.
9. **Kill-test #4 definitions:** "bright" = brightest qualifying detection at t ≤ 18.5 (time-honest); "SN-like" = latest alert-time Fink SIMBAD crossmatch not a stellar/AGN type. Pass if the largest budget with median/B ≥ 2 is ≥ 3 (the §6.3 floor).
10. **No paid model calls** were made (no keys; no approved budget).
11. **KT #3/#4 nights:** measured on the M1 nights 2025-04-19…23 (see `runs/reports/M1.md` for why 2025-04-01…05 was rejected: ZTF recorded no alerts 2025-03-31…04-04). The pool retrieval behind them (ALeRCE public read-only DB superset + time-honest filter) is documented in the M1 report.
12. **KT #10 AstroNotes:** the first crawl hit HTTP 429 on wis-tns.org at 2 s pacing; one retry at 12 s pacing succeeded. No further retries.
13. **Kill-tests are re-runnable offline** (`uv run python scripts/m0_killtests.py --offline`) from the cache; the committed report is from one consistent offline pass.
